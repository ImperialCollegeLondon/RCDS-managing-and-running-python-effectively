## HPC

High Performance Computing (HPC) clusters allow you to run your code on many computers, and doing so will use many of the things you've learned in this course, including creating and configuring an environment, run your code from the command line, and using command line arguments to specify inputs. 

* General information about using the HPC at Imperial can be found [here](https://www.imperial.ac.uk/computational-methods/hpc/).
* Python-specific information for using the HPC at Imperial can be found [here](https://www.imperial.ac.uk/early-career-researcher-institute/learning-and-development/courses-by-programme/research-computing-and-data-science/demystifying-hpc/).
* ECRI courses about using the HPC at Imperial can be found [here](https://www.imperial.ac.uk/computational-methods/hpc/training/) and [here](https://www.imperial.ac.uk/early-career-researcher-institute/learning-and-development/courses-by-programme/research-computing-and-data-science/introduction-to-hpc/)

## Containers

Containers, such as [Docker](https://www.docker.com/) allow you to package your code, along with all of its dependencies, into a single file that can be run on any computer. This is an extension of the idea of a virtual environment, which allows you to package your code and its dependencies into a single directory that can be run on any computer. This can ensure that all developers and users have exactly the same environment, making the code much easier to collaborate on, distribute, and use. It can also be a useful way to run more complex apps to the HPC.

* Python-specific Docker documetnation can be found [here](https://docs.docker.com/guides/python/).
* An ECRI course on containers can be found [here](https://www.imperial.ac.uk/early-career-researcher-institute/learning-and-development/courses-by-programme/research-computing-and-data-science/reproducible--scalable-research-computing-with-containers/)
